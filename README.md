# CodeAlpha - Basic Network Sniffer

## Description
A Python-based network packet sniffer built for the CodeAlpha Cybersecurity Internship.

## Features
- Captures live network traffic on wlan0
- Displays source/destination IPs
- Identifies TCP, UDP, ICMP protocols
- Shows packet payloads

## Requirements
- Python 3
- Scapy library

## Installation
pip install scapy

## Usage
sudo python3 sniffer.py
